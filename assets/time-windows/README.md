# 时空之窗 · 50 幅城市生活情境图

打开仓库根目录的 `time-windows.html`。图册提供城市/年份/主题搜索、地区及年代筛选、浏览器本地收藏、大图、注释开关、任意两幅并排比较，以及同城不同时代的快捷对照。

所有画面为 AI 生成的历史情境插画。年份是约略设定，地理坐标为城市位置；它们不对应已知照片、精确机位或发生过的具体事件。服装、工具、建筑、食物和人物细节可能有误，未经专家逐项审定。馆藏检索链接是进一步阅读入口，不是画面的证据。请勿作为考古复原或史料使用。

图片使用项目内 WebP，无第三方图片热链。列表按需加载缩略图，打开详情后加载大图。离线压缩包解压后可双击 HTML 使用；收藏取决于浏览器本地存储支持。

## 给并行开发者

新增文件集中在 `assets/time-windows/`、`time-windows.html` 与独立离线包。地球页面只增加一个末尾脚本；不修改现有历史数据、渲染函数或布局。脚本用 Shadow DOM 隔离入口样式。原地球应用可独立迭代。

`scenes.json` 是完整数据，`data.js` 为其经典脚本封装以支持离线打开。`scenes-seed.json` 保存 50 个选题和实际生成提示词；`asset-manifest.json` 保存图像 SHA-256。未来修订图片时应一起更新来源与不确定性说明。
