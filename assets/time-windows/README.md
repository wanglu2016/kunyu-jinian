# 时空之窗 · 15幅城市生活情境图

在线入口：https://wanglu2016.github.io/kunyu-jinian/time-windows.html

本版展示已经实际保存并核验的15幅中国城市生活图像，从约前500年的曲阜到约1200年的临安。每幅大图1536×1024，缩略图480×320。支持搜索、年代筛选、浏览器本地收藏、大图、下载和任意两幅比较。详情可回到地球的对应年份和城市视角。

所有画面为AI创作的历史情境插画，年份为约数，坐标为城市附近。建筑、服装、工具、食物与人物细节可能有误，未经专家逐项审定，不作为历史复原或史料。观察提示描述画面与提出问题，不为画面提供历史真实性背书。

`scenes.json` 与 `data.js` 仅包含本版15幅已交付场景。`asset-manifest.json` 记录大图SHA-256；`scenes-seed.json` 保留原50个选题供以后扩展，不代表已制作50张图。未制作的条目不出现在图册中。

本次修改集中在图册文件、地球页入口与可选URL定位、README展示。图册不依赖WebGL，图片采用本地WebP，缩略图懒加载，大图按需打开。收藏只保存在当前浏览器。无独立离线图册下载包；下载仓库后可直接打开 `time-windows.html`。
